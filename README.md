# RescalingPicture.py

PNG画像を指定した倍率で拡大・縮小するデスクトップツールです。ドラッグ&ドロップまたはファイル選択で複数のPNGファイルをまとめて処理できます。

## 主な機能

- **複数ファイルの一括処理**：ファイルを複数選択、またはドラッグ&ドロップでリストに追加し、まとめて変換
- **倍率指定**：数値で拡大・縮小率を指定（例: `2` = 200%、`0.5` = 50%）
- **リサンプリング方式**：`Image.Resampling.NEAREST`（ニアレストネイバー法）を使用。ドット絵やアイコンなど、ぼかさずにくっきり拡大したい画像に適しています
- **保存先の指定**：デフォルトでは元のファイルと同じ場所に保存。チェックを外せば任意のフォルダにまとめて保存可能
- **進捗表示**：処理中のファイル名と進捗バーを表示
- **エラー処理**：一部のファイルが失敗しても処理を続行し、最後に成功・失敗件数をまとめて報告

## 必要環境

- Python 3
- 以下のライブラリ
  ```bash
  pip install pillow tkinterdnd2
  ```

`tkinter` は通常Python本体に同梱されていますが、環境によっては別途インストールが必要な場合があります。

## 使い方

1. スクリプトを実行します。
   ```bash
   python rescaling_picture.py
   ```
2. 「ファイル追加」ボタン、またはウィンドウ内へのドラッグ&ドロップで変換したいPNGファイルを追加します（複数選択可）。
3. 「倍率」欄に拡大・縮小したい倍率を入力します（例: `2` で2倍、`0.5` で半分）。
4. 必要に応じて「保存先」を設定します。
   - 「元のファイルと同じ場所に保存」のチェックを外すと、任意のフォルダを指定できます。
5. 「変換実行」ボタンを押すと、リスト内の全ファイルが一括で変換されます。
6. 完了すると、成功・失敗件数を通知するダイアログが表示されます。

## 出力ファイル名

変換後のファイルは、元のファイル名に倍率を付加した形式で保存されます。

```
元ファイル名_x{倍率}.png
```

例: `sample.png` を2倍に変換した場合 → `sample_x2.png`

## リスト操作

| 操作 | 内容 |
|------|------|
| ファイル追加 | ファイル選択ダイアログから複数のPNGを追加 |
| 選択項目を削除 | リストで選択した項目のみ削除 |
| 全てクリア | リストの内容をすべて削除 |

## 注意事項

- 追加できるのは `.png` 拡張子のファイルのみです。
- 同じファイルを重複して追加することはできません。
- 保存先フォルダを指定する場合、存在するフォルダを選択してください（自動作成はされません）。
